#  MarketGo

**MarketGo** — это бэкенд-сервис доставки еды и платформы электронной коммерции, написанный на языке **Go**. Сервис предоставляет REST API для управления каталогом блюд (меню), корзиной покупок, заказами, авторизацией и профилями пользователей.

---

##  Основной функционал

*  **Аутентификация и профиль (`profile`, `handlers/auth.go`):** Регистрация, вхід, JWT-авторизация (`auth.middleware.go`) и управление профилем пользователя.
*  **Меню и Блюда (`handlers/menu.go`, `models/dish.go`):** Просмотр доступных блюд и категорий меню.
*  **Корзина (`cart/`):** Полный цикл управления корзиной (добавление, изменение количества, удаление элементов, очистка, просмотр и переход к оформлению).
*  **Заказы (`orders/`):** Оформление и просмотр истории заказов.
*  **База данных и Миграции (`database/`, `migrations/`, `schema/`):** Подключение к БД, SQL-миграции таблиц (`users`, `dishes`, `cart`, `orders`) и схемы валидации данных.

---

##  Технологический стек

* **Language:** Go (Golang)
* **Auth:** JWT (JSON Web Tokens) + Bcrypt (`utils/hash.go`)
* **Database:** PostgreSQL / MySQL
* **Migration tool:** SQL migrations (`001` - `004`)

---

##  Инструкция по установке и запуску

### 1. Клонирование репозитория

```bash
git clone https://github.com/lener242/MarketGo.git
cd MarketGo
```

### 2. Установка зависимостей

Убедитесь, что у вас установлен **Go 1.18+**, затем выполните:

```bash
go mod download
```

### 3. Настройка и миграция базы данных

Примените SQL-скрипты из папки `migrations/` в вашей базе данных по порядку:
1. `001_create_users.sql`
2. `002_create_dishes.sql`
3. `003_create_cart.sql`
4. `004_create_orders.sql`

### 4. Запуск приложения

Для запуска сервера выполните:

```bash
go run main.go
```

##  Полная структура проекта

```
MarketGo/
├── cart/                       # Логика работы с корзиной
│   ├── add.go                  # Добавление товара в корзину
│   ├── checkout.go             # Оформление заказа из корзины
│   ├── clear.go                # Очистка корзины
│   ├── remove.go               # Удаление позиций
│   ├── update.go               # Обновление количества
│   └── view.go                 # Просмотр содержимого корзины
├── database/                   # Подключение к базе данных
│   └── db.go                   # Инициализация и соединения с БД
├── handlers/                   # HTTP-обработчики и Middleware
│   ├── auth.go                 # Хэндлеры авторизации
│   ├── auth.middleware.go      # Middleware для проверки JWT
│   ├── menu.go                 # Хэндлеры для работы с меню/блюдами
│   └── response.go             # Вспомогательные функции ответов API
├── migrations/                 # SQL-миграции базы данных
│   ├── 001_create_users.sql    # Таблица пользователей
│   ├── 002_create_dishes.sql   # Таблица блюд/товаров
│   ├── 003_create_cart.sql     # Таблица корзины
│   └── 004_create_orders.sql   # Таблица заказов
├── models/                     # Структуры моделей данных (Go structs)
│   ├── cart.go                 # Модель корзины
│   ├── dish.go                 # Модель блюда/товара
│   ├── order.go                # Модель заказа
│   └── user.go                 # Модель пользователя
├── orders/                     # Управление заказами
│   └── view.go                 # Просмотр истории и деталей заказов
├── profile/                    # Управление профилем пользователя
│   ├── update.go               # Обновление данных профиля
│   └── view.go                 # Просмотр данных профиля
├── routes.go                   # Конфигурация и регистрация эндпоинтов API
├── schema/                     # Схемы данных и валидация
│   ├── cart_schema.go          # Схема корзины
│   ├── dish_schema.go          # Схема блюд
│   └── user_schema.go          # Схема пользователей
├── utils/                      # Вспомогательные утилиты
│   ├── hash.go                 # Хеширование паролей
│   └── jwt.go                  # Генерация и валидация JWT токенов
├── go.mod                      # Файл зависимостей Go
├── go.sum                      # Хеши зависимостей
└── main.go                     # Главная точка входа в приложение
```
